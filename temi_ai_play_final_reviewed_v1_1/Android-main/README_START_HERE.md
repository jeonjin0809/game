# temi AI 놀이 도우미 — 최종 통합 시연 프로젝트 (V1.1)

> 이 ZIP에는 **소스코드**가 들어 있습니다. 설치용 APK는 포함되어 있지 않습니다.
> 기존 템플릿을 기반으로 기능을 통합한 **실기기 검증 전 최종 시연 후보**입니다.

## 처음 시작하는 분: 5분 요약

1. Windows에서 압축을 풀어 **`C:\TemiProjects\Android-main`**처럼 **한글이 없는 영문 경로**에 `Android-main` 폴더 전체를 복사합니다. 기존 G드라이브 한글 경로 오류는 ZIP을 새로 만들어도 그대로 발생할 수 있습니다.
2. Android Studio → **Open** → `settings.gradle.kts`가 들어 있는 `Android-main` 폴더를 선택합니다. **`app`만 열면 안 됩니다.**
3. Gradle JDK는 Android Studio에 설치된 **JDK 17 이상**을 선택합니다. Android Gradle Plugin 9.4.x / Gradle 9.6.0을 사용합니다. 첫 동기화에는 인터넷이 필요합니다.
4. **Build Variants**에서 먼저 `emulatorDebug` 선택 → Android 에뮬레이터에서 `기억·이야기 놀이`를 실행합니다.
5. 5문제 완료 → 첫 메뉴의 `선생님용 · 지난 놀이 기록` → 원하는 기록 선택 → `다음 맞춤 놀이 승인` → 후속 게임을 실행합니다.

**다운로드한 ZIP에서 그대로 열어 빌드했다면 Android Studio 내 Gradle Sync와 Build Output을 확인해야 합니다.** 이 서버에서는 Gradle 배포본을 다운로드할 수 없어 전체 APK 빌드를 완료하지 못했습니다.

## 게임은 두 가지뿐입니다

| 게임 | 설명 |
|---|---|
| **AI 기억·이야기 놀이** | 5개 미션 속에 ① 그림 순서 ② 2×2 위치 ③ 사라진 그림 ④ 이야기 순서를 적어도 한 번씩 체험. 마지막 미션은 다시 연습. 기본 2개 그림부터 시작하며 4~7세 공통으로 **연령 선택은 없음** |
| **숨바꼭질** | 교사가 저장한 안전 장소 **2~3곳**을 천천히 자동 순찰. 도착 후 멈춰 사람 감지. 사람을 찾으면 "찾았다!". 5분에 미달이면 "못 찾겠다 꾀꼬리!", 10분에 종료. 교사 감독 필수 |

### 아이를 돕는 방법

- 기억하기 단계에서는 **말하기 완료 후** 그림을 보여주는 시간을 계산합니다.
- 대답을 고민하면 30초 뒤 한 번만 부드럽게 도움을 안내합니다.
- 힌트는 정답이 아닌 선택지 하나 제거(이야기는 첫 장면 안내), `다른 예시 보기`는 문제 답을 알려주지 않고 풀이 방식만 설명합니다.
- 정답·오답·힌트·예시를 기록하고 AI 또는 규칙이 **다음 미션/그림 수/안내 방식**을 선택합니다.
- 가능한 말을 사전 검토한 한국어 문장으로 제한하며 아이의 능력이나 발달에 대한 진단은 하지 않습니다.
- 포함된 **17개 로컬 그림 파일**은 temi Android 6의 이모지 글꼴에 의존하지 않습니다.

### 교사에게 도움을 주는 방법

- 놀이 기록 **최근 10회**를 기기에 익명 보관합니다(이름/사진/영상/음성 없음).
- 교사가 기록 하나를 골라 **실제로 실행한 미션과 결정 출처**(실제 AI / 규칙 데모 / 오프라인 / 교사 승인)를 확인할 수 있습니다.
- 정답/오답·힌트·예시 요청을 근거로 다음 놀이를 추천하며 **교사 승인** 후 첫 문제와 마지막 문제에 다시 실행합니다.
- 한 세션에서 나온 기록은 **발달·심리 진단이 아니라 놀이 관찰 자료**입니다.

## 실제 AI를 사용하려면

노트북에서 **Python 3**으로 `start_agent_demo.bat`를 더블클릭해 서버를 실행합니다(다른 패키지 설치 불필요). 서버 화면에 `MODE=demo`라면 **규칙 데모이며 AI가 아닙니다.**

노트북과 로봇이 같은 신뢰할 수 있는 Wi-Fi에 있을 때, temi 시작 메뉴의 `선생님용 · AI 서버 설정/연결 확인`에 `http://[노트북 IPv4 주소]:8765`를 입력합니다. 예: `http://192.168.0.15:8765` (예시 주소). 일반 Android 에뮬레이터에서 같은 컴퓨터 서버라면 `http://10.0.2.2:8765`가 가능합니다. Windows 방화벽에서 **개인 네트워크** 접근을 허용해야 할 수 있습니다.

실제 LLM 판단에는 OpenAI API 키를 **노트북의 환경변수**에만 설정하고 서버를 재시작합니다. 앱 소스나 로봇에 API 키를 넣지 마세요. API 요금은 ChatGPT 구독과 별개입니다.

```powershell
$secureKey = Read-Host "OpenAI API Key" -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $secureKey).Password
$env:OPENAI_MODEL = 'gpt-4.1-mini'
py -3 ai-server/server.py
```

실제 모델 호출 결과가 검증되지 않으면 앱은 오프라인 규칙으로 돌아가며 **실제 AI 판단이라고 표시하지 않습니다**. 네트워크 오류가 나도 게임은 계속 진행됩니다.

## 실제 temi에서 실행 전 반드시

1. Build Variants에서 **`temiDebug`** 선택. 설치는 Android Studio의 연결 기기 메뉴를 사용합니다.
2. temi **런처/권한 호환성**과 앱의 **SETTINGS 권한**, Kiosk 설정, 사람 감지 모드를 확인합니다.
3. 숨바꼭질을 시작하기 전에 교사가 로봇 앞 1~1.5m 안쪽에 서서 **사람 감지 테스트 성공** 메시지를 확인해야 합니다. 이벤트가 없으면 게임 시작 버튼이 비활성화됩니다.
4. 교실/강의실의 평평한 바닥에 저장한 위치 **2~3곳**만 선택하고, 계단·전선·가방·로봇 이동 중 뛰어드는 사람이 없도록 통제합니다.
5. 발견된 참가자는 교사가 미리 정한 대기구역으로 이동합니다. **동일인을 얼굴로 구분하지 않습니다.**
6. 실제 사람이 없는 상태에서 TTS, 이동, 장애물 정지, 긴급 중단까지 순서대로 테스트합니다.
